## Best Practices

### Content Organization

1. **Structure your content hierarchically**: Use proper heading levels (H1 → H2 → H3) to create a logical document structure
2. **Keep sections focused**: Each section should cover one main topic or concept
3. **Use visual hierarchy**: Leverage headings, lists, and spacing to guide readers
4. **Include code examples**: Demonstrate concepts with practical examples
5. **Add tables for reference**: Use tables to present structured data

### PDF Optimization

1. **Test your exports**: Always preview generated PDFs to ensure formatting is correct
2. **Use print-friendly styles**: Avoid elements that don't work well in print (animations, videos)
3. **Consider page width**: Default 850px works well for most content, but adjust as needed
4. **Optimize images**: Use appropriately sized images to keep file sizes reasonable
5. **Handle authentication**: For protected docs, ensure cookie forwarding is working

### Performance Tips

1. **Lazy load images wisely**: The plugin scrolls to trigger lazy images, so use lazy loading strategically
2. **Minimize external resources**: Reduce dependencies on external stylesheets or scripts
3. **Cache appropriately**: Consider implementing client-side caching for frequent exports
4. **Monitor timeouts**: Increase timeout values for large or complex pages
5. **Test in production**: Verify Puppeteer works in your deployment environment

## Technical Implementation

### How It Works

The PDF export process follows these steps:

1. **Request initiated**: User clicks the export button
2. **API route called**: Browser sends request to `/api/export-pdf?path=/docs/page`
3. **Puppeteer launches**: Server starts a headless Chrome instance
4. **Page navigation**: Puppeteer navigates to the specified page URL
5. **Cookie forwarding**: Request cookies are forwarded to the browser
6. **Accordion expansion**: Plugin clicks accordion triggers (up to 5 iterations)
7. **Image loading**: Plugin scrolls through page to trigger lazy images
8. **Content extraction**: Main content is extracted using `contentSelector`
9. **DOM cleanup**: Navigation, sidebars, and UI elements are removed
10. **Custom transformations**: Any `beforePdfGeneration` code is executed
11. **Height calculation**: Plugin calculates total content height
12. **PDF generation**: Chrome generates PDF with calculated dimensions
13. **Response**: PDF is streamed back to the client
14. **Download**: Browser triggers file download
